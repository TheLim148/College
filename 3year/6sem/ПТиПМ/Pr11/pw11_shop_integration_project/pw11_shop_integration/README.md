# Практическая работа 11: интеграционное тестирование

## Состав проекта

- `src/cart.py` — модуль A: расчёт суммы корзины.
- `src/discount.py` — модуль B: расчёт скидки.
- `src/payment.py` — модуль C: проверка оплаты.
- `src/order_service.py` — интеграционный слой A -> B -> C.
- `tests/test_integration.py` — интеграционные тесты.

## Как запустить

```bash
python -m unittest discover -s tests -v
```

В проекте специально оставлена ошибка для демонстрации интеграционного тестирования:
интеграционный слой передаёт тип пользователя как `premium`, а модуль скидок сравнивает
значение с `Premium`. Из-за этого скидка не применяется на стыке модулей.
