# Console Text Editor

Простой учебный консольный текстовый редактор на C++17.

Что умеет:
- создавать новый документ;
- открывать и сохранять обычные `.txt` файлы;
- открывать и сохранять собственные `.btxt` файлы;
- шифровать и расшифровывать `.btxt` через XOR по строковому ключу;
- хранить текст в фиксированном двумерном массиве символов;
- выбрасывать собственные исключения для ошибок, связанных с `.btxt`.

## Ограничения
- максимум 200 строк;
- максимум 255 символов в строке.

## Структура `.btxt`
В бинарный файл записываются:
1. сигнатура `BTXT`;
2. версия формата;
3. размер зашифрованных данных;
4. checksum исходного текста;
5. зашифрованные данные.

## Сборка через Makefile
```bash
make
./.target/editor
```

## Сборка через CMake
```bash
cmake -S . -B build
cmake --build build
./build/editor
```
